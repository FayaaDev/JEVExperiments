# JEV Experiments

Each experiment lives in its own project folder:

- **[JevTickets](JevTickets/)** — configurable local Jev-AR classification of Excel text columns. See [usage](JevTickets/JEVAR-WORKFLOWS.md) and the [workflow explainer](JevTickets/generic-jevar-workflow.html).
- **[GroupStudy](GroupStudy/)** — WhatsApp interaction classification, usefulness reviews, spreadsheets, CSV exports, and GroupStudy theme files. See the [workflow explainer](GroupStudy/classification-workflow.html).

Run project commands from the corresponding project folder. Keep each project's scripts, input data, generated results, and documentation together.
