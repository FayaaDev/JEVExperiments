Generic Jev-AR classification workflow

One script, configurable question and labels, local model predictions

The script reads an Excel text column, asks Jev-AR to choose among your configured labels, and writes predictions to a new workbook.

The complete flow

The script checks configuration, file paths, the column header, and the model's token budget. It refuses to overwrite an existing output file.

C

How you define the decision

Example configuration:

{
  "instruction": "Which support team should handle this customer ticket?",
  "routes": {
    "Billing": "Invoices, charges, payments, and refunds.",
    "Technical support": "Errors, broken features, and integration problems.",
    "Account access": "Login, passwords, and locked accounts.",
    "Other": "Requests outside these categories."
  }
}

For each valid row, the script calls:

result = router.route(text, routes, instruction)

Jev-AR reads the text, question, and route descriptions together. It scores the routes and returns the highest-scoring label.

For example, a duplicate-charge complaint should route to Billing. A forgotten-password ticket should route to Account access.

Change the JSON to classify sentiment, comment purpose, or another workflow. The script needs no task-specific code or retraining.

D

What each row produces

Output column Meaning
Jev-AR route The highest-scoring configured label
Jev-AR confidence The score for that label
Jev-AR probabilities Scores for all configured labels, stored as JSON
Jev-AR needs review Flags low confidence or an input the script could not classify
Jev-AR review reason Explains the review flag

Low-confidence text still receives a prediction. Blank, formula, non-text, and overlength cells receive no prediction and a review reason.

The script reuses predictions for repeated text. It retains original workbook data and other sheets in the new file.

Unlike the earlier usefulness workflow, this script does not run a second AI review or load saved review decisions.

E

Run it and understand the limits

uv run classify_with_jevar.py tickets.xlsx tickets-routed.xlsx --column Message --config ticket-routing.json

This command labels tickets in a workbook. It does not send tickets to support teams, reply to customers, or change a ticketing system.

The script uses the model's built-in review threshold. Confidence is not measured accuracy for your business; test representative tickets before relying on predictions.

The script does not open links. It skips overlength text rather than silently truncating it or assuming how to combine passages.

Model inference stays local. Dependency installation may need network access. Commercial use requires appropriate permission under the model's license.
